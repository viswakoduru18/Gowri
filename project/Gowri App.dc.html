1Gowri consumer app · interactive prototype + two Home directions
Assumptions
App: Gowri, "For a Beautiful Life" (web store: mysaalife.com). Wellness / OTC / personal care; no prescription flow yet (needs a separate workflow). India, INR, GST-inclusive prices. Warm, friendly copy. iOS frame shown; layout is identical on Android.
Zoho → App (read)
Items API: name, SKU, MRP, selling rate, GST %, pack size, stock per warehouse, images, description. Shown live as price, "In stock / Only N left", delivery estimate. Sales Order + Package / Shipment status drive Order Tracking. Books invoice → downloadable GST invoice.
App → Zoho (write, via Gowri backend)
Contact (customer), Sales Order with line items / coupon, payment record, shipping address, cancellation & return (credit note). The app never holds Zoho credentials; the backend talks to Zoho over OAuth. Stock reserved on order, released on cancel.
